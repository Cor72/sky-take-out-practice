## 排查 sky-take-out 启动失败（Error starting ApplicationContext）

- 用户只改了一行：`WebMvcConfiguration.docket()` 里加 `log.info("准备生成接口文档...")`（git diff 已确认仅此一行）。这行**不是**原因。
- 复现到真实异常：`java.lang.ClassFormatError: Invalid method Code length 0 in class file com/sky/properties/AliOssProperties`。
- 定位：`sky-common/target/classes/com/sky/properties/AliOssProperties.class`（时间戳 10-23 21:54，IDEA 编译产物）的**无参构造 Code 属性长度为 0**（javap 显示 `public AliOssProperties(); Code:` 后面为空），Lombok 生成的字节码损坏，Spring 解析 bean 类型时类加载失败 → 上下文刷新失败。
- 修复：`mvn -DskipTests clean package`（JDK 17）重新编译，字节码恢复正常，`Started SkyApplication ... port 8080` 启动成功。源码未改动。
