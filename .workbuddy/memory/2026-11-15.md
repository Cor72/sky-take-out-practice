## 修复 GlobalExceptionHandler 编译报错（后端起不来、doc.html 打不开）
- 根因：`GlobalExceptionHandler` 引用 `MessageConstant.ALREADY_EXIST`，但 `MessageConstant` 里没定义（课程版常量叫 `ALREADY_EXISTS`，这份代码也没有）→ IDEA 报 `Cannot resolve symbol`，编译不过。
- 修复：在 `sky-common/src/main/java/com/sky/constant/MessageConstant.java` 补 `public static final String ALREADY_EXIST = "已存在";`，与当前源码引用名保持一致，不动 GlobalExceptionHandler。
- 环境：命令行 PATH 里没有 `mvn`（IDEA 用内置 Maven），未能在命令行验证编译；默认 `java` 是 25，JDK 17 在 `D:/Program Files/Java/jdk-17`。

## Knife4j 调试 POST /admin/employee 返回 401
- 根因：`WebMvcConfiguration` 注册 `JwtTokenAdminInterceptor` 拦截 `/admin/**`，只放行 `/admin/employee/login`；请求头缺 `token` → `preHandle` 里 parseJWT 抛异常 → `response.setStatus(401)` + `return false`，响应体 0 字节。
- 解决：先调登录接口（admin/123456）拿 `data.token`，再到 Knife4j「文档管理 → 全局参数设置」加 Header 参数 `token`（`application.yml` 里 `admin-token-name: token`）。token 有效期 2h（`admin-ttl: 7200000`），过期会再变 401。
- 概念澄清：本项目成功响应是 HTTP 200 + body `code:1`；业务成败看 body 的 `code`（1 成功 / 0 失败），别和 HTTP 状态码混。201 需显式 `@ResponseStatus(HttpStatus.CREATED)` 或 `ResponseEntity.created()`，代码里没有。
- 关联：username 重复时走 `GlobalExceptionHandler` 的 Duplicate entry 分支，返回 HTTP 200 但 body 为 `{"code":0,"msg":"xxx已存在"}`，用的正是本次补的常量。
